Reference Library
Three ways to find and use research papers
📎
Import by PMID
Paste paper IDs — the app fetches title, authors, journal, abstract, and full text (for open-access papers) from PubMed automatically.
🔍
PubMed Search
Type a keyword to search PubMed from within the app. Up to 10 results with abstracts. One click adds any result to your library.
💬
Ask Your Library
Ask a natural-language question — "What does MAIA show about OS?" — and AI searches your imported papers and streams back a cited answer.
How AI uses your library: Each paper has a Use in AI toggle. Only toggled-on papers are passed as context — the model writes from your evidence base, not from general training knowledge. Toggle individual papers on/off, or use Select All / Deselect All.

Quality Assurance
AI-powered checks before you submit
📊 Paper Flow Check
Analyses ALL sections together and checks whether the article reads as a coherent whole. Returns:
  • Overall one-sentence verdict
  • Section-by-section transition score (✅ / ⚠️ / ❌)
  • Specific issues named by section pair
  • Numbered, actionable recommendations
Each recommendation has a one-click Fix button — AI rewrites that section using surrounding sections as context.
✏️ Grammar & Style Check
Checks each section for passive voice overuse, sentence length, academic register, and hedging. One-click applies suggested fixes — streams corrected text for your review before you accept.
📚 Version History
Save named snapshots at any point ("after reviewer comments"). Restore any previous version — the current state is always saved first, so no work is ever lost.
🔒 Lock & Share
Lock an article to prevent accidental edits. Generate a read-only shareable link for co-authors to review without an account.

Settings & Personalisation
Configure the tool to match your workflow
🔑 Bring Your Own API Key
Use your own Groq, OpenAI, or OpenRouter account. Keys are stored encrypted and never shown after saving. Falls back to the shared server key if not set.
🤖 AI Provider & Model
Choose your provider and model. Default: Groq Llama 3.3 70B. Claude and Gemini support coming in a future sprint. Dynamic model list fetched automatically.
🌐 Output Language
Select the language for all AI-generated content. PubMed sources are always in English — the AI synthesises them in the language you choose.
🎨 Writing Style
Choose preset academic writing styles (concise, verbose, clinical, narrative) or paste a writing sample. AI matches your preferred tone, sentence length, and citation density.
🔒 Strict Mode
Block AI generation unless at least one paper is selected in the library — guarantees every paragraph is always evidence-grounded.
🔬 NCBI API Key
Add your own NCBI key to raise the PubMed rate limit from 3 to 10 requests per second — useful for batch PMID imports.
